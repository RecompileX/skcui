# SKCUI Releases

**SKCUI** stands for **Simple Keyboard Console UI**.

| Package | Contents | Requirements |
| --- | --- | --- |
| [Stable](stable/README.md) | Current component API: menus, checkboxes, text, input fields, separators, and progress bars | C++20+; bundled CMake example uses C++23 |
| [Stable 1.x](stable%201.x/README.md) | C++17 function API with menus and checkboxes | C++17+ |

Each package includes `src/skcui.hpp`, `examples/full-example.cpp`, a CMake example project, a setup guide, and an MIT license.

Use [stable](stable/README.md) for the component API. Choose [stable 1.x](stable%201.x/README.md) when your project needs C++17 or the function API. The development header is `../dev/skcui.hpp`.

See the [current API reference](../docs/api.md) or the [stable 1.x API reference](stable%201.x/docs/api.md).
