# SKCUI v0.1.0

SKCUI v0.1.0 is the first packaged release of the header-only console-menu library.

## Highlights

- Interactive Up/Down navigation with Enter selection
- Optional menu title and description
- Windows, Linux, and macOS input implementations
- Self-contained public header and example under `release/`

## Requirements

- C++17-compatible compiler
- ANSI-compatible terminal

## Build the example

From an x64 Visual Studio Developer Command Prompt:

```bat
cl /nologo /std:c++17 /EHsc /W4 /I release\src release\example\example.cpp /Fe:skcui-example.exe
```

## Verification

The release header and example were compiled with MSVC using `/std:c++17` and `/EHsc`. The key-handling loop reads one keyboard event per iteration.

Linux and macOS source paths are included but were not executed on this Windows release host.
